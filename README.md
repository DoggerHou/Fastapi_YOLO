# Fastapi_YOLO — детекция людей на снимках с БПЛА

Программный сервис для автоматизированного обнаружения людей на изображениях и видеозаписях с беспилотных летательных аппаратов (БПЛА).  
В основе лежит нейросетевая модель семейства YOLO11, развёрнутая через REST API на FastAPI и упакованная в Docker-контейнер с поддержкой GPU.

> Проект реализован в рамках выпускной квалификационной работы.
